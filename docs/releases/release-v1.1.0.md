# Duck on Desk 1.1.0

本地测试版，尚未提交 Git 或发布。机器人实验室加入更直观的关节控制、训练教程和训练过程可视化。

## 认识和控制机器人

- 14 路模型输出按左腿、头颈、右腿显示中文部位和作用，并与半透明 3D 模型联动；喙部动画独立显示，不再被误认为第 15 路策略输出。
- 暂停时拖动关节即可查看姿态；运行或单步时再进行物理模拟。提供实际角度、目标角度、模型输出与变化曲线。

- 镜头随机器人水平移动，保留手动旋转、缩放和平移；重置身体与切换预设视角后继续跟随。

## 学习强化学习

- 「训练与策略」按认识任务、制定奖励、开始练习、检验结果分成四步。奖励滑块可生成脚本，高级参数与策略网络可展开编辑。
- 展示所选训练任务的平均奖励、策略 loss 和价值 loss 曲线。
- 可随时开关真实训练的 3D 预览，默认关闭；抽样显示第一个训练环境，训练无需等待动画播放。
- 新工作台与 MCP 机器人实验默认使用实测方案：MPS 训练与推理、目标速度 0.25 m/s、200 轮、8 个环境、128 步、学习率 0.001、种子 2。奖励包含方向与转速惩罚，教学滑块生成的脚本保留这两项。
- 预览候选策略时同步该次训练的目标速度。训练记录、模型导出、评测、应用与回退继续保留。

## 安装包修复

- 训练进程禁止在应用包内生成 Python 字节码缓存，避免首次训练后破坏 macOS 的签名校验。

## 本地测试

从「设置 → 关于 → 打开开发者模式」进入实验室。已有工作台仍可保存自定义设置；本机工作台已切换为上述实测方案。训练需要已有的 PyTorch、MuJoCo、ONNX 和 ONNX Runtime Python 环境。

推荐方案在本机 M3 Max 上约需 3 分钟。三种子原生评测及浏览器评测各 30 秒均未跌倒；推荐模型浏览器速度误差下降约 10.8%，仍有约 22.7° 的方向漂移，尚未达到目标速度或精准直线行走。完整证据见 [训练报告](../diagnostics/training-parameters-2026-09-09/README.md)。CUDA 待 NVIDIA 实机验证。

本地 arm64 包复用用户级 Hugging Face 模型缓存，不内嵌训练权重；不自动训练或更换桌宠当前策略。本次不发布更新，也不触发 GitHub CI。macOS 使用 ad-hoc 签名。

### 本地追加：动作库与第二课

Duck 右键新增动作菜单、啄地和行走时随机播放开关；动作统一经过站稳、播放、站稳、恢复当前行走的流程。第二课「先学会倒立」支持从站立练翻转与稳定支撑，自定义 Reward 直接可见，模型可试播、检查与导出。下一阶段再练恢复正立；街舞入口已移除，待完整动作跑通后再开放，历史实验保留。

基础练习尚未训练起身，不能加入桌宠动作库或替换行走模型。MPS 200／CPU 500 轮均未学会稳定倒立，界面如实显示目标未完成；默认参数仍为探索起点。CUDA 待实机验证。


### 本地追加：实验室 Dock／任务栏

实验室存在期间 macOS Dock 保持可见，关闭后恢复当前桌宠偏好；恢复最小化窗口、Dock 激活及关闭再开已覆盖。Windows 显式保留普通窗口的任务栏和聚焦属性，Alt+Tab／任务栏实机待验。5,859 Node 测试及实际 app.asar 的 macOS 窗口／关于页入口检查通过。用户在第 603 轮终止该次训练后，此修复已安装到本地 1.1.0。


倒立 Reward 已升级为姿态 v2：计入头部支撑、躯干／腿部碰地、双脚相对身体的位置、重心偏移和实际关节运动；修正横躺或反复翻滚持续得分的问题。训练页新增连续保持时间、姿态达标占比和奖励分项，保留完整自定义脚本。新规则经 50 轮 MPS 短训和原生／WASM 检查，仍未学会倒立，继续标为探索参数。
