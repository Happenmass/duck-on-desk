# Robot Lab：认识身体与第一次强化学习实验

2026-09-09：上述功能纳入本地 1.1.0 测试版；公开版本仍为 v1.0.0。安装与包内验证见 `docs/diagnostics/local-1.1.0-2026-09-09.md`。

## 怎么用

打开开发者模式后，先看「认识与控制」。点左侧通道或机器人上的编号，就能看到对应部位、用途和角度范围。

- 左侧按头颈、左腿、右腿筛选；编号对应模型输出顺序，右边的数字是关节目标角度。
- 中间是实际仿真模型的透视视图，选中部位会高亮。连线连接输出通道、真实关节位置和右侧控制面板。镜头自动跟随机器人水平位移，并保留手动旋转、缩放和平移；重置身体后也会跟回起点。可切换实体材质、旋转相机或选择正面、侧面、俯视。
- 右侧用中文说明身体部位，角度以度显示。拖动、输入数字或点击 ±5° 都会立即摆姿。
- 摆姿是暂停状态下的运动学预览，会直接修改仿真姿态。点击「运行仿真」或「单步」后，MuJoCo 才重新计算物理运动并维持手动目标；这时机器人可能失去平衡。
- 「恢复模型控制」释放全部手动目标，随后点击运行；「重置身体」恢复站姿和模型控制。
- 「这一路如何映射？」展示零起始输出索引、技术名称、站姿偏置、控制目标和真实模型输出。手动模式明确显示「未经过模型」，暂停前从未推理过时显示「尚未运行」。角度曲线来自实际关节状态，不生成装饰性数据。

## 14 路输出的实际映射

当前 ONNX 接口是 `[1,61] → [1,14]`，14 个执行器来自同一个 MJCF 和 `JOINT_NAMES`。界面编号从 01 开始，`actions` 索引从 0 开始。喙部是独立视觉动画，不占用行走策略输出；不能将其伪装成第 15 路模型输出。

| 界面编号 | 模型输出 | 关节 | 部位 / 动作 |
|---|---|---|---|
| 01 | actions[0] | left_hip_yaw | 左髋转向 |
| 02 | actions[1] | left_hip_roll | 左髋侧摆 |
| 03 | actions[2] | left_hip_pitch | 左髋前后摆 |
| 04 | actions[3] | left_knee | 左膝弯曲 |
| 05 | actions[4] | left_ankle | 左脚踝俯仰 |
| 06 | actions[5] | neck_pitch | 颈部前后倾 |
| 07 | actions[6] | head_pitch | 头部上下点 |
| 08 | actions[7] | head_yaw | 头部左右转 |
| 09 | actions[8] | head_roll | 头部左右歪 |
| 10 | actions[9] | right_hip_yaw | 右髋转向 |
| 11 | actions[10] | right_hip_roll | 右髋侧摆 |
| 12 | actions[11] | right_hip_pitch | 右髋前后摆 |
| 13 | actions[12] | right_knee | 右膝弯曲 |
| 14 | actions[13] | right_ankle | 右脚踝俯仰 |

模型控制时：`target = DEFAULT_POSE + actions`，原始单位是弧度；UI 将两者换算为度显示。模型控制周期为 50 Hz。数据连线只在仿真运行时播放流动效果。

## 训练页面

「训练与策略」按四步组织，所有步骤都能随时切换：

1. **认识任务**：设定走路速度，点击了解环境、观察、动作、奖励和学习。用一个小问题理解“只奖励站稳，可能不会向前走”。这次练习会在已有基础行走策略上继续训练。
2. **制定奖励**：用滑块设计速度、直立和大动作惩罚的权重。滑块只修改草稿；点击「使用这些评分规则」后才替换奖励脚本，下次训练生效。两门课都直接显示「自定义奖励（Reward）」编辑框，可修改完整 Python 脚本；第 3 步也能一键跳回。切换课程保留各自的草稿，修改只用于下次启动的训练。
3. **开始练习**：默认 200 轮用于观察趋势，实际耗时取决于采样量与设备。Python 路径、评测设备、采样参数、学习率和种子收进「训练环境与高级参数」；策略网络也可展开编辑。
4. **检验结果**：查看训练前后的速度误差、跌倒比例，载入候选看动作，再执行桌宠仿真环境中的对比。通过原有评测门槛后才允许应用；导出与恢复上一策略仍可用。

新工作台和 MCP 机器人实验使用[官方全量微调设置](../../mcp/robot-lab/presets/official-finetune/README.md)：目标 0.25 m/s、200 轮、8 环境、128 步、lr=.0001、seed=2，配套方向奖励。两课均从官方原始权重独立开始，直接更新官方网络的全部策略层；输入标准化保持不变。旧修正网络稳定配方的报告仅作为历史证据，不代表新方法已验证稳定。自定义奖励与训练参数可编辑，3D 预览仍默认关闭。

右侧一直显示所选记录的平均奖励曲线，两条 loss 在「深入了解：模型如何调整」中展开。每秒读取已完成轮次，三图独立刻度，悬停或方向键可对齐查看同一轮。新任务或缺失指标显示空态，不补零。奖励升高只表示更符合当前评分规则；是否真的走得更好，要看第 4 步。

### 可选的训练现场 3D

- 默认关闭；点击「开启 3D 预览」后，以最多 10 Hz 抽样显示第 1 个真实 MuJoCo 训练环境。来自当前状态的根位置、四元数和 14 个关节角度，不生成代替训练的演示动画。
- 预览标明训练前试走、采集经验、更新策略、训练后试走，以及采样轮次、仿真时间。它不是完整轨迹回放；训练跑得快时画面会跳过中间动作。
- 独立 Three.js 只读视图没有物理、策略推理或阴影，像素比最多 1.25，绘制最多 15 fps 且只在姿态、相机或尺寸改变时重画。关闭、离开训练 tab 或页面不可见时释放视图；训练继续。控制页隐藏时也停止其绘制。
- 训练器只有收到 3 秒短租约才写最新一份姿态文件，租约每 0.5 秒检查。关掉预览会撤销租约；窗口意外消失也会在租约到期后停止采样。关闭状态仍有很轻的租约检查，不宣称后端绝对零开销。
- 帧数据独立于训练指标，不累计姿态历史。关闭预览不影响奖励、loss 或模型更新。旧训练记录没有现场数据，会明确提示；完成记录仅显示最后采样，不冒充实时动作。

## 动作菜单与第二课：倒立保持

Duck 右键菜单新增「动作」：可以点击「啄地」，也可以开启「行走时随机播放」。普通脚态连续行走时，在 25–55 秒的随机间隔后选一个动作。小鸭先停下站稳，完成动作后再站稳，接着按当前有效指令行走。睡眠、提起、状态切换会中断动作；滚轮和高跷不使用普通脚训练的动作。

「训练／管理动作」打开第二课「倒立保持」。环境提供接近头撑的初态并加入小扰动，先学保持，之后再练从站立翻转、恢复正立。课程选择保留平地行走、倒立保持和单列的历史翻转实验，各自草稿独立；保留可编辑 Reward、策略网络、MPS／CUDA 配置、真实训练曲线与可选 3D。街舞入口暂时移除，等完整动作跑通后再做；恢复正立课程尚未开放。

倒立基础模型只供试播、检查与导出，暂不能加入桌宠动作库；须先训练回到正立的完整动作。当前动作库仍可试播预置啄地、移出已添加动作，行走模型独立保留。历史街舞实验、奖励脚本和权重未删除，仍可通过 MCP 的 lab_training_list / lab_training_get / lab_policy_artifact 查询。

历史站立起步倒立目标的 MPS 200／CPU 500／MPS 1,000 轮均未学会稳定倒立。UI 标为「训练结束 · 目标未完成」，保留候选供观察。此模板是探索起点，不是成功配方。报告见 [动作测试](../diagnostics/duck-actions-2026-09-09.md)。

2026-09-09：两门课均支持手动设置 1–2,000 轮，单次训练上限延长至 2 小时，默认仍为 200 轮。界面、MCP 和实际执行端已统一；可点击「停止练习」中止。更多轮数提供更多尝试，不保证能学会倒立。


### 历史街舞实验的 Reward（已后置，2026-09-09）

原安装版入口在「训练与策略 → 制定奖励 → 看看评分规则如何写成代码」，需要展开。修正版把编辑框直接展示，并增加「开始练习 → 查看 / 修改奖励脚本」、脚本状态字段说明和默认模板评分表；当时因 2,000 轮训练正在运行而暂缓；训练结束后已随倒立基础课一起安装到本地 1.1.0。默认 Reward 源码 `mcp/robot-lab/training/action-reward.py` 未改。

每段 8 秒，`p = 已用时间 / 8`。前 0.4 秒目标直立；0.4–2 秒逐渐转为倒立；2–5.2 秒保持倒立；5.2–6.8 秒回正；最后 1.2 秒目标直立。它是固定时间表，不是“练会一阶段再进入下一阶段”的课程训练。

每步总分为 `3 × 姿态匹配 + 高度匹配 + 倒立阶段权重 × 倒立腾空 - 0.03 × 自身前后速度² - 0.002 × 关节指令平方和 - 0.05 × 相邻指令变化平方和`。姿态分使用方向误差的指数函数；高度目标以基座 12 cm 为中心，倒立阶段增加周期性 0–4 cm 抬升。腾空项要求 `upright < -0.7` 且没有部位接地。

这个模板没有动作示范、接触部位目标、转体或音乐节奏评分；首轮 200 轮未学会。动作入库另查倒立时长、腾空落地和收尾站稳，奖励升高不能替代这道检查。


### 历史阶段：从站立学习倒立（2026-09-09，已后置）

这一旧实验曾作为第二课，现保留为「历史实验 · 从站立翻转（旧）」，使用下述奖励与站立起步规则；右键入口现已改为先练倒立保持，旧记录不改变含义。

基础练习每段从站立开始，持续 8 秒。默认奖励已改为姿态 v2：同时看头部支撑、躯干与腿部是否躺地、双脚是否高于身体、重心偏移和实际关节运动。取消无条件翻转持续加分；首次翻转进展每段累计最多 0.5，连续达标保持逐渐加分，中断归零。代码可在「制定奖励 → 自定义奖励」直接编辑，字段、权重和通过条件均在页面说明中。

训练曲线新增本轮最长连续保持、姿态达标时间占比和可核对的奖励分项。训练峰值可能只来自一只机器人，最终仍要在三段站立起步测试结尾各保持 2 秒；旧记录缺失的指标保持空白。分项只是可选日志函数，真正用于训练的始终是 reward_environment 返回值。姿态阈值与字段见 `mcp/robot-lab/docs/scripts.md`。新旧奖励尺度不同，不能直接用分数大小比较动作进步。

通过标准是原生 3 段和浏览器 1 段各自从站立开始，在结尾连续 2 秒保持身体朝下、头部接地、双脚离地且碰撞中心高度 >8 cm，水平速度 <0.1 m/s，角速度 <1 rad/s。短暂翻滚或腾空不会通过；结果显示最长连续保持与结尾保持时间。

该阶段的导出模型标为 `practice`，支持试播、检查与导出；8 秒试播后停在当前姿态。由于尚未练习站回原位，即使通过倒立检查也暂不加入桌宠动作库，更不会覆盖行走策略。下一阶段再处理起身与完整站立到站立的动作。

实际训练与本地安装状态见 [本地验证](../diagnostics/local-1.1.0-2026-09-09.md)。模板默认 200 轮是探索起点，不能当作训练成功的保证。

### 当前第二课：先练保持（2026-09-09）

任务 `microduck-headstand-hold` 从物理采样的近头撑姿态开始，加入小幅初始速度扰动。之后只由模型输出关节目标，没有持续托举、锁姿态或改变重力。先学保持，后续再把站立起步、翻转进入和恢复正立连起来；初始倒立是环境提供的，不能算自主翻转。

奖励把身体竖直倒置角度、重心、腿部高度与头接地的反馈组合起来，不要求各关节匹配固定姿势，连续严格达标另加保持分。保持课默认随机初始化、可显式选择官方步态权重作对照，全量训练 61→512→256→128→14 / ELU 网络，不叠加小网络、不限制为参考角度附近的修正；参考姿态只用于环境初态；旧奖励脚本所需的参考误差字段仍保留。新版探索噪声从 0.15 rad 起步，由 PPO 学习；旧记录续训保留原 0.04→0.01 rad 日程。奖励仍可自定义，界面只读展示官方网络结构。默认 200 轮为探索参数，不承诺成功。

新训练从近倒立初态跨轮连续模拟，允许失稳后用脚蹬地恢复，不按8秒重置；最终原生 3 段与 WASM 1 段都从近倒立起步，完整运行 8 秒、中途不重置，结尾连续 2 秒严格达标才通过。结果带独立保持版本与初态标记，即使通过也只保留为练习模型，不进入桌宠动作库或替换行走策略。


### 继续上次训练

在“训练与策略”右侧选择一条记录，查看“已保存到第几轮”，填写“接着这条记录再练多少轮”，点击“继续这次训练”。例如已保存 2,000 轮、追加 2,000 轮，新记录累计目标为 4,000 轮。续训继承原记录的奖励、学习率与设备，左侧草稿只用于“从官方权重新建训练”。

每 10 轮自动保存检查点；点击“停止并保存”会完成当前轮再保存。停止后可以继续，但要完成一个训练段才能评测或导出 ONNX。新记录保留原始实验，曲线展示本次新增轮次，横轴与步数累计。每段最多 2,000 轮／2 小时，可重复追加。

新检查点恢复模型、价值网络、优化器、仿真及随机状态，探索幅度不会重新从头衰减。旧版官方全量微调检查点也可续训，但从新的仿真初态开始；旧的小修正网络不能混用，没有检查点的已停止实验也无法补回权重。意外断电或强制退出只能恢复最近保存的进度。


### 身体角度与随机初始化（当前第二课）

第二课默认随机初始化网络，第一课默认官方步态权重；“新训练的起点”可以切换二者作对照。网络结构一样，初始参数不同。随机模式的所有线性层（包括输出层）随机且可训练，输入使用固定 mean=0／scale=1；官方模式保持上游权重与输入标准化。价值网络在新任务中随机初始化，续训则连同优化器一起恢复。

倒立保持奖励关注身体轴接近竖直倒置、重心靠近头部支撑位置、双脚离地和实际稳定性，不再奖励固定关节形状。身体角度项为 exp(-(θ/0.5)^2)，θ 是身体轴与竖直倒置方向的夹角（弧度）。原模型关节范围保留，没有额外 ±.2 rad 限制。腿部可以在模型范围内寻找平衡姿势。

仿真仍从接近倒立的位置起步，带轻微扰动；这不表示已经学会从站立翻过去。旧记录继续训练仍用旧奖励与原初始化来源；使用新身体角度奖励／随机起点需新建训练，不能把旧续训结果当作新方案的验证。


## 2026-09-09 本机 PPO 参数更新

在第 3 步展开“训练环境与高级参数”，点击“使用本机推荐参数”：32 环境 × 每环境 64 步，每轮 2048 样本；行走学习率上限 0.0001，倒立保持 0.0003。按钮不改奖励、初始化选择、种子、轮数或历史记录。学习率输入在新版代表初始值及上限，实际值随 KL 调整。

每环境 64 步累计模拟 1.28 秒，不是每轮重新开始：回合跨轮持续，到达时限或失败才重置。200 轮为 409600 样本；2000 轮为 4096000 样本，并非成功保证。官方 4096×24 的单轮采样量是本机的 48 倍。

新训练默认 local-ppo-v2：5 遍、4 小批更新，gamma=.99、lambda=.95、clip=.2、价值损失系数1、价值裁剪、梯度范数上限1、目标KL=.01、熵系数.001。critic 使用 512/256/128 ELU 隐层；actor 保持原有官方结构。探索标准差随机初始化模式从 .15 rad、官方权重模式从 .025 rad 起步，逐关节学习；.01–.5 约束的是采样噪声，不限制策略均值和关节活动范围。回合超时补价值估计，真实失败不补；曲线仍显示实际奖励。

旧记录与缺少 ppo_profile 的旧 MCP 草稿继续使用 legacy-v1（原价值网络、4 次整批更新、固定学习率及旧探索规则）。续训从源检查点恢复方案、critic、优化器、探索参数与实际学习率；不会改用新版默认。要比较新版请开始新训练。

这不是完整复刻官方训练环境：本机仍是 CPU MuJoCo＋MPS/CUDA 网络计算，没有 GPU 批量物理、critic 特权观测或在线观测归一化；初始化、奖励和物理边界按本项目课程约定。CUDA 待实机验证。详见 [参数核验](../diagnostics/ppo-parameters-2026-09-09.md)。


## 2026-09-09：允许蹬地恢复

第二课新训练默认 `reset_on_pose_loss=false`、`hold_episode_steps=0`：只在开始时摆初态，倾斜、碰地、采样轮结束和经过8秒都不重置，也不因失稳额外扣终止的2分。直到用户停止或达到本次训练预算，仿真持续运行；非法动作／非有限奖励报错停止。默认奖励取消脚触地的单独扣分，保留身体竖直、支撑对齐、离地高度、身体躺地与运动代价；既不奖励触地次数，也不钉死腿部姿势。

脚触地或暂时失衡会让严格倒立保持计时归零，但机器人可以继续恢复。评测仍完整8秒、中途不重置，结尾连续2秒严格倒立才达标；允许恢复不等于放宽为任何躺地／蹬腿动作都成功。

新建训练使用此规则。为保证历史实验可复现，旧记录续训保留原重置规则和原奖励，右侧会明确提示。旧MCP草稿缺少字段时仍使用原规则；要在新草稿中启用，设置reset_on_pose_loss=false、hold_episode_steps=0并采用相应奖励脚本。旧权重不会被覆盖，运行中的任务不受代码更新影响。

## 1.1.1：按模拟时间重置

第二课在第 3 步显示「多久重置一次（模拟秒）」，新训练默认 30 秒，输入 0～1000 的整数秒；0 关闭定时重置。每次回到近倒立初态并加入扰动；失稳或脚触地不提前结束，仍可以尝试恢复。每秒对应 50 个控制步，30 秒即 1500 步，与电脑实际耗时无关。

切换课程保留当前草稿时间。修改只影响新训练；继续历史任务保留检查点的重置规则，记录下方会显示实际时间及是否因失稳重置。以前不按时间重置的记录继续保持 0，不会自动套用 30 秒。正式评测仍为完整 8 秒，中途不重置。此节替代此前新训练默认无限连续的说明。
