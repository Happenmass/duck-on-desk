## 已实现

本地 1.1.0 已更新到 `/Applications/Duck on Desk.app`。第二课与 Duck 右键训练入口改为「倒立保持」，独立任务 `microduck-headstand-hold`。旧 `microduck-headstand` 保留为「历史实验 · 从站立翻转（旧）」，原始训练记录、奖励和起步／验收含义不变；街舞继续后置。

- 训练、原生评测、WASM 试播／评测共享 `headstand-hold.json` 的近头撑初态。姿态来自真实物理采样，参考目标做过固定控制探测；不是已经学会的站立起步动作，也不是已验证稳定八秒的构型。
- 初始速度带小扰动；之后只有关节策略控制，没有持续托举、锁定姿态或修改重力。初始保持计时为零。
- 策略绕头撑参考关节目标学习最多 0.2 rad 的修正，不使用冻结的行走模型驱动倒立。仍为 61 输入／14 输出 ONNX，用户可编辑奖励与修正网络。
- 奖励提供分项姿态反馈和严格连续保持奖励，降低全部条件相乘造成的反馈缺失。探索标准差从 .04 降到 .01 rad；同轮采样和 PPO 更新使用相同分布。
- 训练每段最多八秒；半秒后失去倒置或其他身体接地时终止并扣分。评测完整八秒，中途不重置，结尾连续两秒严格达标才通过。
- 结果标记 `goal=headstand-hold`、`initialization=near-headstand`、`evaluation_version=headstand-hold-v1`。无论保持评测是否通过，都仅为 practice，不能替换行走或加入桌宠动作库。
- 教程路线：先保持 → 从站立进入 → 恢复正立 → 街舞。后续阶段没有在本次冒充已实现。

## 网络结构核对（2026-09-09）

直接读取当前缓存的官方 `BEST_alpha_walking.onnx`：61 → 512 → 256 → 128 → 14，隐藏层 ELU，输入含 Sub／Div 标准化，共 197,774 个线性层权重／偏置参数。当前可编辑修正网络为 61 → 64 → 14、Tanh，共 4,878 参数；官方推理策略约为其 40.5 倍。这里只核对部署的 actor，不由 ONNX 推断官方训练 critic 或全部训练配置。

默认脚本的“zero initial correction preserves the base walking policy”注释来自行走课，在保持课中已经不准确：HoldActor 不使用官方步态网络，其输出为头撑参考关节目标加 0.2 × tanh(修正网络输出)，最后按关节范围限幅。零初始化仅作用于最后一层，使初始修正为零，不是把整个网络置零。保持课真正可学习的控制器目前只有这 4,878 参数。

容量不足是值得对照验证的因素，现有实验没有隔离出其影响。候选对照可为 61 → 256 → 128 → 14（50,574 参数），同时保持奖励、初态、采样步数、种子和噪声一致，比较原生／WASM 连续保持；更大网络不会自动突破外层 ±0.2 rad 的修正范围。此次仅核对结构，未修改训练代码或启动新训练。
