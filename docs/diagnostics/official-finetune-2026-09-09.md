# 官方网络全量微调（2026-09-09）

## 当前实现

按用户纠正，行走课与倒立保持课均从同一份官方原始步态 ONNX 开始，保留 **61→512→256→128→14 / ELU** 策略结构、全部原始权重与输入标准化，PPO 直接更新全部 **197,774** 个策略参数。不再使用附加修正网络、冻结步态底座、输出层清零或头撑参考角度 ±0.2 rad 的输出限制。

两课分别初始化官方原始权重，没有把旧修正网络候选当成原始权重。`official_finetune_policy` 校验声明的层尺寸／ELU 后严格载入官方参数；不兼容的旧策略草稿显式失败，不能悄悄退回残差训练。界面只读展示官方结构，奖励和 PPO 参数仍可编辑。训练结果记录网络结构、训练方法、初始化哈希、逐参数张量变化与导出误差。

保持课继续近头撑起步；预设角度只服务于环境初态和奖励参考。新动作策略的观测保持官方命令槽语义，速度／头部命令为零，时间阶段仍可供奖励读取。原生训练／评测与 WASM 试播／评测按 `policy_observations` 元数据分发；旧模型继续使用原来的阶段输入，不更改历史任务、模型或评测意义。

价值网络是独立的训练辅助网络，不导出；这里保证与官方部署策略 actor 一致，没有声称复刻未取得的官方 critic 或整个官方训练工程。

默认全量微调起点为 MPS、200 轮、8 环境、128 步、lr=.0001、seed=2；行走速度 .25 m/s。原 `stable-flat-walk` 参数／脚本／实测证据保留为历史残差方案，新默认在 `presets/official-finetune`，不能继承旧方案的稳定性结论。读取旧工作台时采用官方网络模板，识别到旧工厂模板配套 .001 学习率时改为 .0001，用户奖励及其他设置保留，原磁盘文件不在读取时改写。
