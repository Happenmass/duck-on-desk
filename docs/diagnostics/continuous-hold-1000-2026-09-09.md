## 实际结果

| 检查 | 结果 |
| --- | --- |
| 原生 MPS：3 段各 8 秒，从近倒立初态起步 | 成功率 0/3；三段最长保持的最小值 0.06 秒；结尾保持最小值 0 秒 |
| CPU 检查点复测：同样 3 段各 8 秒 | 同上，0.06 秒，未达标 |
| 包内 ONNX / WASM：1 段完整 8 秒 | 最长保持 0.08 秒、结尾 0 秒，未达标 |
| 从最终训练环境 0/1/2 的实际状态继续，各 20 秒 | 不重置、不加探索噪声，三段严格保持均 0；机体 upright < −0.8 的时间占比也均为 0 |
| ONNX 导出数值核对 | 最大绝对误差 2.98e−7；导出成功不代表动作成功 |

最终训练状态的 32 只机器人都有头接触和脚接触，均无额外身体触地。躯干离倒立竖直方向仍有 **49.15°～57.10°**。延续测试中三只脚接触占比都为 100%，没有恢复到倒立方向。这不只是「脚触地令严格指标不通过」：身体角度本身也未达到。

浏览器又用「看看训练后的动作」完整试播到 8 秒并暂停，实际姿态截图位于证据目录 `wasm/evaluation-pose.png`；其起点是近倒立初态，不是训练末尾状态。截图可见头颈与腿折叠，不能称为倒立保持。

## 奖励与样本

第 1000 轮平均奖励为 **0.57959**，构成为：身体姿态 +0.64848、连续保持 0、身体触地 0、运动代价 −0.06171、指令变化 −0.00718、自动终止惩罚 0。

严格达标样本共 195 条，占 2,048,000 条的约 **0.00952%**，全部在第一轮；该轮包含环境设置的近倒立初态，不能视为学会恢复。第 2～1000 轮达标占比与连续保持奖励均为 0。全程记录中的最长保持 0.28 秒也出自第一轮。

中途只读评测检查点（CPU，三段最长保持的最小值）：90 轮 0.20 秒、210 轮 0.26 秒、510 轮 0.02 秒、740 轮 0.12 秒、1000 轮 0.06 秒。每次另从前三个实际训练状态继续 20 秒，均未恢复倒立。检查点读取为原子文件快照，评测不改变训练状态、权重或随机数流；本次未额外保存中间权重副本。

**事实**：策略后期减少了身体躺地，获得部分姿态分，但停留在头和脚同时支撑的倾斜状态；奖励上升没有对应倒立保持的改善。

**推断**：连续不重置后，接近目标的有效样本只在起始短片段出现，后续主要学习失稳状态附近的行为；当前姿态分仍允许倾斜支撑获得正奖励。这两个方向值得继续诊断，但本次单种子实验不能独立证明各自的因果贡献，也不能据此断言再增加轮数一定无效。未擅自改变用户要求的重置规则或继续开新训练。
