# 倒立课：允许用脚蹬地恢复，连续模拟

2026-09-09。用户要求失去倒立后不要重置，希望策略可以用脚蹬地重新平衡。本次修改训练终止规则和默认脚触地奖励，不改变官方网络结构、初始化约定或模型关节范围。Git未更新。

## 最终行为

- 第二课新训练只在开始时设置一次近倒立初态，之后跨rollout连续模拟；身体倾斜、身体碰地、脚落地都不触发状态重置，8秒也不再自动重开。达到本次训练轮数／时间预算或用户停止时保存进度；非法动作或非有限奖励报错停止。
- 默认参数 `reset_on_pose_loss=false`、`hold_episode_steps=0`。0表示不按时间重置；非零表示控制步上限（MCP范围0..50000）。继续新记录恢复相同规则和仿真状态，不重新摆姿势。
- 默认奖励移除脚触地的单独 −0.25 扣分；取消因失稳终止导致的 −2 分。身体竖直、重心对齐、抬腿、身体躺地代价与运动代价保留。不给触地次数／反复蹬地本身加分，仍根据身体平衡结果给分。
- 严格保持计时与物理状态分开：脚落地或失衡会令hold_seconds归零，但仿真继续。最终评测依然从独立近倒立初态运行8秒，中途不重置，最后2秒严格倒立才达标。允许蹬地恢复不等于已经学会，也不把躺地算作倒立。
- 旧MCP草稿／检查点缺字段时保留 `reset_on_pose_loss=true`、`hold_episode_steps=400`；继续旧记录保留原奖励与原规则。UI明确提示。若要使用连续恢复规则，在第二课新建训练；旧记录和模型未被覆盖。
- 连续训练中phase=age/400可以大于1；默认保持奖励不用phase，策略观测仍为官方零指令语义。
