# 2026-09-09：实跑后的稳定训练参数

推荐使用 [MPS 平地行走参数包](../../../mcp/robot-lab/presets/stable-flat-walk/README.md)，固定 seed=2。此次完成 9 次真实 PPO 训练，另有 2 次探索任务因已定位问题而主动停止；全部经官方 MCP SDK 写稿、校验、启动及读取产物。

## 推荐配置

MPS 训练与评测、目标速度 0.25 m/s、200 轮、8 个环境、每轮 128 步、学习率 0.001、seed=2、默认 61→64→14 修正网络，搭配参数包内的方向奖励脚本。每次 204,800 环境步，Apple M3 Max 实测约 183～195 秒。筛选时 3D 预览关闭。

奖励：速度跟踪权重 1，直立 0.5，离地 0.5，动作平方惩罚 0.002，朝向误差平方惩罚 5.0，转动速度平方惩罚 0.02；训练器跌倒再扣 2 分。奖励脚本是方案的一部分，不能只修改数字而保留旧奖励。

## 三个训练种子的对照

原生评测为 12 个初始条件 × 30 秒，包含与桌宠相同的完全静止起点；另外在实际浏览器 WASM 中各测 30 秒。原生基础模型平均速度误差约 13.74 cm/s，浏览器约 13.68 cm/s。均不使用桌宠位移补偿、起步加速或姿态辅助。

| seed | 训练耗时 | 原生误差下降 | 原生最大偏航 | 浏览器误差下降 | 浏览器最大偏航 | 跌倒 |
|---|---|---|---|---|---|---|
| 0 | 191.27 s | 12.71% | 10.72° | 12.84% | 35.00° | 原生 / 浏览器均 0 |
| 1 | 195.26 s | 16.68% | 15.22° | 17.43% | 60.34° | 原生 / 浏览器均 0 |
| 2 | 183.30 s | 11.14% | 21.26° | 10.82% | 22.66° | 原生 / 浏览器均 0 |

选择 seed=2 是因为它在原生与浏览器中的方向结果最接近，而且浏览器方向偏差最小；不是因为它奖励最高。seed=1 虽然速度误差更低，但浏览器偏航达到约 60°，因此不选。

推荐模型在浏览器里：平均速度误差 0.1367935 → 0.1219954 m/s，下降 10.82%；平均身体前进速度约 0.1132 → 0.1280 m/s，30 秒世界 X 位移 3.24 → 3.62 m。最大偏航约 22.66°，仍有方向漂移，尚未达到精准直线或目标 0.25 m/s。这里的“稳定”是这组平地、短程条件下训练无数值失败、能导出且不跌倒，不代表任意场景或长时间都不倒。

三次训练的完整指标和哈希保留在原始报告。推荐 seed=2 的前 / 后 10 轮平均奖励为 1.5753 / 1.6126，价值 loss 首尾为 560.09 / 327.32。奖励和 policy loss 不保证单调，不能把下跌或接近零直接等同于动作更好。

## 筛选中排除的方案

- 旧默认 0.15 m/s：20 轮独立 20 秒评测中速度误差仅改善约 0.016%，主要站在原地。增加到 100 / 200 轮仍未出现实质改善。
- 基础模型指令扫描：0.15 m/s 时实际速度约 0.0004 m/s；0.225 / 0.25 时能持续迈步，实际约 0.098 / 0.111 m/s。这是当前基础模型的起步特性，不能归因于模型已经学会 0.15 m/s 行走。
- 0.25 m/s、100 轮、lr=0.0003：有小幅改善，原生误差下降约 0.8%，浏览器约 0.5%。
- 200 轮、lr=0.001、旧奖励：速度改善明显，但两个训练种子的原生最大偏航约 142° / 97°，因此不推荐。
- 方向惩罚 0.5：仍偏航约 75°；提高至 5.0 后再做上述多种子复测。
